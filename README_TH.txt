EA Column and Wall Search 1.0.3
แก้ Copy Data: เฉพาะแถวข้อมูล ไม่มีหัวตาราง ไม่มีเครื่องหมายคำพูดครอบค่า ใช้ Tab คั่น 7 คอลัมน์
ตรรกะ Engine สำหรับ Import/Search/PT/Save/Export ไม่เปลี่ยนจาก 1.0.0
EA_Search.ico และ EA_Search_Icon.png แนบไว้สำหรับใช้กับ Shortcut หรือเอกสาร
===============================
โปรแกรม Windows สำหรับเตรียมข้อมูล Column/Wall จาก ETABS Access โดยฟังก์ชันงานหลักใช้ออฟไลน์ได้
ไม่มี AI และไม่ใช้โทเคนขณะเปิดใช้งาน; จะเชื่อม GitHub API เฉพาะเมื่อผู้ใช้กด Check Update

เริ่มใช้งาน
1. Save project ในโปรแกรมรุ่นเก่าก่อนปิด
2. แตก ZIP แล้วเปิด EA_Search_1.0.3.exe ไม่ต้องเปิด Excel และไม่ต้อง Run as Administrator
3. Open project เพื่อเปิด .easearch เดิมจากรุ่น 0.1.x ได้
   แนะนำ Save เป็นชื่อใหม่เพื่อเก็บต้นฉบับ เผื่อต้องย้อนกลับ
4. ต้องใช้ Windows 64-bit, .NET Framework 4.x และ Access ACE OLEDB 12.0 แบบ 64-bit
   เครื่องอื่นอาจต้องติดตั้งไดรเวอร์ Access ที่เหมาะสม ไม่ควรปิดระบบป้องกันไวรัส

เมนูแบ่งกลุ่ม
DATA & PROJECT : Type/Version, Import Access, Save project, Open project
SEARCH & PT    : Search, Prepare PT, Append PT
OUTPUT         : Output Names, Export CSV, Copy Data
UPDATE & HELP  : ตรวจสอบรุ่นใหม่จาก GitHub และวิธีใช้
ใช้เมนู File / Edit / Project / View / Help ด้านบนแทนปุ่มได้เช่นกัน
ปุ่ม Check Update ใช้อินเทอร์เน็ตเฉพาะตอนกด เพื่อตรวจ GitHub Releases หากมีรุ่นใหม่จะเปิดหน้าดาวน์โหลดในเว็บเบราว์เซอร์
โปรแกรมไม่เก็บ GitHub token และไม่ดาวน์โหลด/ติดตั้งไฟล์ทับโดยอัตโนมัติ
หากหน้าต่างแคบ ให้ขยายหน้าต่างหรือเลื่อนแถบเมนูแนวนอน

วิธีทำงาน
1. เลือก WALL/COLUMN และ 2020/2016/9.7.4 ให้ตรงกับไฟล์ที่จะนำเข้า
2. Import Access เลือกหลายไฟล์ได้ แต่ในแต่ละรอบต้องเป็นประเภทและเวอร์ชันเดียวกัน
   นำเข้าประเภท/เวอร์ชันอื่นเพิ่มในรอบถัดไปได้
   นำเข้าไฟล์พาธเดิมและประเภทเดิมจะทดแทนชุดเดิม ไม่เพิ่มซ้ำ
   ถ้ามีไฟล์ผิดในรอบนั้น ข้อมูลเดิมจะไม่ถูกเปลี่ยน
3. ติ๊ก Members และ Stories แล้วกด Search
   ช่อง Find ค้นบางส่วนของชื่อได้ ไม่แยกตัวพิมพ์เล็ก/ใหญ่
   รายการที่ติ๊กไว้ยังคงอยู่แม้ถูกซ่อนด้วยตัวกรอง
   All/None มีผลเฉพาะรายการที่มองเห็น ล้างช่อง Find ก่อนกด None หากต้องการล้างทั้งหมด
4. Prepare PT แสดงเฉพาะชั้นในผล Search
   กรอกโมเมนต์แล้ว Append PT ใช้กับ UDCON1-4 เท่านั้น
   ช่องว่าง = ค่าเดิม, 0 = ศูนย์, ค่าลบใช้ได้, ค่า P ไม่เปลี่ยน
   หนึ่งชั้นใช้ PT ร่วมกันกับสมาชิก/แหล่งที่เลือกของประเภทนั้นในชั้นเดียวกัน
   กด Append ซ้ำไม่สะสม PT ซ้ำ
5. Export CSV หรือ Copy Data เพื่อส่งต่อผล
   Copy Data ไม่มีหัวตารางและใช้ Tab คั่น 7 คอลัมน์ ไม่เพิ่มเครื่องหมายคำพูดครอบค่า
   ใน PROKON ให้วางที่ช่อง Load case ของแถวข้อมูลแรก และตรวจค่าที่ปลายทางก่อนใช้
   ชื่อข้อมูลเดิมรวมถึงเครื่องหมายขีด/underscore ยังคงเดิม ไม่ถูกตัดทิ้ง
   หากเคยวางหัวตารางจากรุ่นเก่า ให้ล้างข้อมูลที่วางผิดก่อนวางใหม่
   ทดสอบรูปแบบข้อความแล้ว แต่ยังไม่ได้ทดสอบวางผ่านหน้าจอ PROKON บนเครื่องนี้
   ก่อนนำไป PROKON ต้องเลือก/จัดคอลัมน์ให้ตรงรูปแบบที่ปลายทางต้องการ
   ไม่ใช่การสร้างไฟล์ .C13 หรือนำเข้า PROKON อัตโนมัติ
6. Save project เก็บข้อมูลนำเข้า, PT และ Output Names ในไฟล์ .easearch
   ยังไม่เก็บรายการติ๊ก/ผลค้นหาล่าสุด เมื่อเปิดงานให้เลือกและ Search ใหม่

Output Names Search (เพิ่มใน 1.0.0)
- พิมพ์คำค้นใน Find แล้วกด Search หรือ Enter, กด Clear เพื่อแสดงทั้งหมด
- ค้นจาก Source ID, Original Member และ Output Name
- อักขระพิเศษ เช่น [ ] ' % * ถูกค้นแบบข้อความ ไม่ใช่ wildcard
- แก้ได้เฉพาะ Output Name ชื่อสมาชิกใน Story-OutputName-Case
- Apply all edits บันทึกทุกแถวที่แก้ รวมแถวที่ถูกซ่อนด้วยคำค้น
- Cancel ยกเลิกการแก้ชื่อในหน้าต่างนั้น
- หลัง Apply ให้ Search ใหม่ แล้ว Save project เพื่อเก็บชื่อถาวร
- ไม่มี [S001] ใน Designation แต่ยังแสดงใน Members/Imports เพื่อระบุแหล่ง
- หากผลลัพธ์ชื่อซ้ำจากหลายแหล่ง จะให้แก้ชื่อหรือเลือกแหล่งเดียวก่อนแสดงผล
  ไม่รวมแรงจากคนละแหล่งให้อัตโนมัติ

การล้างข้อมูล
Imports > Remove selected source ลบเฉพาะข้อมูลแหล่งที่เลือกในโปรแกรม
Clear current Type ลบข้อมูลนำเข้าและ PT ของประเภทที่เลือก
ไม่มีคำสั่งใดแก้ไขหรือลบ Access/XLSM ต้นฉบับ
หลัง Import/Remove/เปลี่ยนรายการที่เลือก ให้ Search ใหม่

กติกาและข้อจำกัด
- Mx=M3, My=M2, P=Abs(min P) ภายในกลุ่ม Source+Story+Member+Case ตาม XLSM ล่าสุด
- COLUMN ใช้ Station ต่ำสุด=Bottom สูงสุด=Top; WALL ใช้ตำแหน่ง Top/Bottom
- ต้องส่งออกต้นทางเป็น kN/kNm อยู่แล้ว โปรแกรมยังไม่ตรวจหรือแปลงหน่วยให้
- ไม่ดึง XLSM หรือ PT จาก XLSM เดิมโดยตรง
- ไฟล์ .easearch มีข้อมูลโครงการและพาธต้นทาง ไม่ได้เข้ารหัส
- การปล่อยรุ่น 1.0.0 ไม่ใช่การรับรองแบบหรือผลออกแบบโดยวิศวกร
  ผู้ใช้งานต้องตรวจหน่วย เครื่องหมาย กติกาการเลือกแรง และผลลัพธ์ก่อนนำไปออกแบบ

การตรวจรุ่นนี้
อ่าน Access จริง 6 ไฟล์รวม 410,424 แถว ผ่านทั้ง WALL/COLUMN และทั้ง 3 เวอร์ชัน
ตรวจค่าแรงตัวอย่างอย่างอิสระ, PT ศูนย์/ว่าง/ลบ, ชื่อชั้นพิเศษ, นำเข้าซ้ำ/ผิดประเภท
ตรวจ Save/Open และ project รุ่น 0.1.0/0.1.1/0.1.2
ตรวจ Output Names 2,000 รายการ การค้นชื่อ/Source/อักขระพิเศษ
ตรวจแก้ไขขณะกรอง, แถวที่ซ่อน, Apply และ Cancel พร้อมตรวจหน้าจอ
ยังไม่ได้เทียบผลทุกแถวกับ XLSM หรือทดสอบบนเครื่องอื่น
